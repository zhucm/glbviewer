# GLB Viewer

独立的本地 GLB 模型预览工具。支持普通 GLB 和使用 `EXT_meshopt_compression` 的 GLB。使用 Three.js 渲染，Vite 提供本地页面和只读目录服务。

## 安装与运行

需要 Node.js 和 npm。在本项目目录运行：

```bash
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:5174/>。`npm run build` 生成 `dist/`；`npm run preview` 可预览构建结果。

## 选择模型

- **选择文件夹**：使用浏览器目录读取接口，按子目录结构显示可展开的 `.glb` 文件树。列表优先使用同目录、同名的图片或 `thumbnail.png` 作为缩略图；没有配图时，仅对滚动到视野中的模型按需生成缩略图。此功能需要支持 `showDirectoryPicker()` 的浏览器，例如 Chrome 或 Edge。
- **选择文件**：使用浏览器文件选择器打开指定的 GLB 文件，列表中的缩略图按需生成。
- **拖入文件**：将一个或多个 `.glb` 文件拖入页面，右侧预览窗口会显示虚线框；新文件会追加到现有列表，并自动预览这次拖入的第一个模型。重复拖入已有文件会直接选中原条目；其他文件不会加入列表。
- **在线链接**：点击与本机来源并列的“在线链接”，在弹窗中输入 HTTP(S) GLB 直链并点击“打开”或按 Enter。模型加载成功后才会追加到现有列表；加载失败的链接不会加入列表，重复地址只选中已有条目。浏览器会在本机保存最近成功打开的 10 条地址，点击记录可再次打开并加入当前列表。例如 <https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/main/Models/Avocado/glTF-Binary/Avocado.glb>。地址无效或加载失败时可在弹窗内修改重试；远程站点需允许浏览器跨域读取。预览在线模型时，可点击左上角地址右侧的图标复制链接。

模型列表可切换“列表”和“图标”视图。图标视图在默认宽度下每行显示约 5 个缩略图，文件夹仍按原有层级展开；鼠标悬停在缩略图上可查看文件路径。网格视图的删除图标在桌面鼠标悬停或键盘聚焦时显示，移动端始终显示。两种视图都可点击条目上的删除图标，仅从当前列表移除模型；列表标题旁的清空图标可移除全部条目并关闭当前预览。这些操作不会删除本机文件或远程模型。桌面端可拖动列表与预览之间的分隔线调整两侧宽度，也可聚焦分隔线后按左右方向键调整。

模型加载后可旋转、平移、缩放和重置视角；点击场景顶部中央的自动旋转图标后，模型会绕自身中心沿画面竖直轴顺时针旋转。点击其右侧的重置视角图标会停止自动旋转，并恢复模型方向和相机位置。拖动分割条调整预览宽度时，相机会保留当前观察方向并重新调整距离，使模型完整显示。页面还会显示包围盒尺寸及三角形数量。预览场景使用柔和的环境光和定向光，显示模型的立体形状。
如果 GLB 含有动画片段，列表和图标视图的缩略图角落会显示播放标记；场景顶部也会出现播放按钮，点击可播放或暂停第一个动画片段。无动画时不显示播放按钮。切换或移除模型时会停止旧动画。
单击模型可选中并高亮点中的连续材质区域，单击空白处取消选择；拖动仍用于旋转视角。区域按 GLB 已有的几何与材质边界识别，不会改写或导出模型。在线 GLB 下载时，若能获取总大小则显示实际下载百分比，并在下载完成后提示解析阶段；否则显示已下载字节数。模型解析本身没有百分比进度。
选择文件夹后只显示目录列表，点击模型时才预览；选择文件时会自动预览第一个 GLB。

## 配合 glbcreater

`glbcreater` 将生成的 GLB 写入配置的输出目录，并保留相对子目录结构。在 GLB Viewer 中点击“选择文件夹”，选中该输出目录即可浏览生成结果。两个项目独立安装、运行；无需复制模型到本仓库。
